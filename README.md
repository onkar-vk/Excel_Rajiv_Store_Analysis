# Rajiv_Store_Annual_Analysis_MS-Excel_Project: 

**Rajiv Store Annual Analysis and Build Interactive Dashboard using Advanced Excel** :

Rajiv Store Analysis report solve many problems and try to improve the sales and revenue:

**1. Goal** : The primary goal of this project is to analyze Rajiv store performance data to identify sales trends, optimize inventory, and understand customer behavior. The project also involves creating an interactive dashboard to present actionable insights for stakeholders, aiding in data-driven decision-making.

**2. Project Description**: The project focuses on analyzing transactional data from a retail store to assess key performance metrics such as sales revenue, product performance, and customer demographics. The dataset includes details about sales, products, customers, and time-based performance metrics.

**Key steps in the project include:**
- Cleaning and organizing raw data for analysis.
- Performing exploratory data analysis (EDA) to uncover trends.
- Creating an interactive dashboard that visualizes metrics like total revenue, top-5 selling states, customer segmentation, and monthly trends, Mostly used order channels 
The final deliverable is a user-friendly dashboard that allows management to monitor store performance and make strategic adjustments in real time.

**3. Skills**
- Data Analysis: Data wrangling, descriptive statistics, and EDA to interpret and summarize the data.
- Dashboard Design: Designing intuitive and interactive visualizations for stakeholders.
- Problem Solving: Identifying inefficiencies in operations and uncovering growth opportunities.

**4. Technologies**
- SQL: For querying databases and extracting relevant data.
- Power Dax Query: For cleaning, data analyzing 
- Power BI: To design and build interactive dashboards and visualizing data.
- Advanced Excel: Pivot table, Sum, Max Function. For data summarization and pivot table analysis.

**5. Findings Summary**
- Sales Insights based on top 5 states in country
- Order vs sales proportion monthly manner
- Top ordered channels insight
- Orders based on age and gender
- Sales Based on Male and Female
- Whats is the order status ?
- Sales Performance, Seasonal spikes observed during festivals and weekends, 
- Customer Insights, Geographic Trends,Inventory Management.
